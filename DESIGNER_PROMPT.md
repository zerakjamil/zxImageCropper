# Designer Prompt for ZXImageCropper Logo + Icon

Use this exact prompt with your designer:

Design a minimal, premium app identity for a macOS utility called ZXImageCropper.

Goal:
Create a logo that communicates precise image cropping, fast workflow, and reliability, while feeling native to macOS.

Brand personality:
- Clean
- Confident
- Precise
- Lightweight
- Modern and timeless

Visual direction:
- Minimal geometric style, no clutter
- Core motif should combine:
  1) crop-frame corners, and
  2) a subtle ZX monogram or abstract diagonal mark
- Avoid generic camera or photo symbols unless heavily abstracted
- Icon must be legible at very small sizes (16 px and 32 px)
- Should look great in both light and dark macOS environments

Color direction:
- Primary: deep slate or graphite base
- Accent: electric cyan/blue for precision highlights
- Keep palette restrained (2 to 3 core colors)
- Include monochrome version (black/white)

Style constraints:
- No gradients that reduce clarity at small sizes
- No thin hairline details that disappear when scaled
- No busy shadows
- No skeuomorphic style

Deliverables required:
1) Primary logo lockup (icon + wordmark: ZXImageCropper)
2) Icon-only mark optimized for app icon
3) Monochrome variants (light and dark)
4) SVG source files (clean vector paths)
5) 1024x1024 PNG export for app icon pipeline
6) Safe-area and spacing guidance
7) Color tokens in HEX

App icon production constraints:
- Must remain recognizable when reduced to 16x16
- Strong silhouette is mandatory
- Center-weighted composition
- Balanced negative space
- Keep line weights optically consistent across scales

Optional exploration:
- A variant where crop corners form a subtle Z shape
- A variant where the X is implied through negative space

Output format from designer:
- 2 to 3 concept directions
- Each concept with rationale (2 to 4 bullets)
- One final recommended direction and why it best fits the product
